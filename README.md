## PCKB — 个人代码知识库

把写过、学过和收藏过的代码，整理成可以长期搜索、理解、学习和复用的个人知识库。

**简体中文 + English · Local-first · macOS Apple Silicon · Public Preview**

支持 Project、标签与学习状态管理，全文搜索和可选的语义搜索；也可以选择 Ollama、DeepSeek 或 Qwen 辅助理解代码，并在本机备份和恢复。
